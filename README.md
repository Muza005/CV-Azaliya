# Azaliya — portfolio

Portfolio site of Azaliya Yagnyaeva, concept artist & 2D animator.

Everything is in a single self-contained file, `index.html` (styles, scripts and images are embedded).
Open it in a browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main` / root).

Pages: Home · Work (gallery and index) · Project · About · Contact. The layout adapts to phones (≤ 820 px).
